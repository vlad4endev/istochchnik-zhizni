# PWA Автоматическое Обновление

Приложение настроено для автоматического обновления PWA на мобильных телефонах и браузерах.

## Как это работает

### 1. **Vite PWA Configuration** (`vite.config.ts`)
- ✅ `registerType: 'autoUpdate'` - автоматически проверяет обновления
- ✅ `skipWaiting: true` - новый Service Worker активируется сразу без ожидания
- ✅ `clientsClaim: true` - новый SW контролирует все открытые страницы сразу
- ✅ `pollInterval: 60000` - проверка обновлений каждые 60 секунд

### 2. **Service Worker Обновление** (`main.tsx`)
Код инициализирует автоматическую проверку обновлений:
- Проверяет обновления каждые 60 секунд
- При обнаружении обновления автоматически перезагружает страницу
- Использует события `controllerchange` для отслеживания обновлений

### 3. **Компоненты для UI**

#### `UpdateNotification.tsx`
Компонент который показывает уведомление пользователю об обновлении. Можно добавить в Layout:

```jsx
import { UpdateNotification } from './features/pwa';

export function Layout() {
  return (
    <>
      <Main />
      <UpdateNotification autoReload={true} />
    </>
  );
}
```

#### `useServiceWorkerUpdate.ts`
Hook для программного управления обновлениями:

```jsx
function MyComponent() {
  const updatePrompt = useServiceWorkerUpdate({ showPrompt: true });

  return (
    <>
      {updatePrompt.show && (
        <button onClick={updatePrompt.onUpdate}>
          Обновить приложение
        </button>
      )}
    </>
  );
}
```

## Как работает обновление для пользователя

### На браузере (Desktop)
1. При каждой загрузке страницы Service Worker проверяет обновления
2. Если доступно обновление, оно загружается в фоне
3. При следующей перезагрузке или через 60 секунд - новая версия активируется
4. Страница перезагружается автоматически

### На PWA приложении (установленном на телефон)
1. Приложение периодически проверяет обновления в фоне (каждые 60 сек, когда приложение открыто)
2. При обнаружении обновления оно загружается
3. При следующем открытии приложения новая версия будет активна
4. Пользователь не должен переустанавливать приложение - все происходит автоматически

## Cache Busting

Vite автоматически добавляет хэш версии для всех файлов в production:
- `app.abc123.js` → если содержимое изменилось, здается новый хэш
- `style.def456.css` → старый кэш автоматически инвалидируется

Workbox отслеживает эти изменения и автоматически обновляет кэш.

## Отладка

В консоли браузера вы увидите логи:
```
[PWA] Service Worker обновлён, перезагружаем приложение
```

Для просмотра Service Worker у себя в браузере:
- Chrome DevTools → Application → Service Workers
- Там видно когда был последний обновлен Service Worker

## Файлы

- `vite.config.ts` - конфиг PWA с Workbox
- `src/main.tsx` - инициализация проверки обновлений
- `src/features/pwa/` - компоненты и hooks для UI
  - `UpdateNotification.tsx` - компонент уведомления
  - `UpdateNotification.css` - стили
  - `useServiceWorkerUpdate.ts` - hook для управления обновлениями
  - `index.ts` - экспорты
