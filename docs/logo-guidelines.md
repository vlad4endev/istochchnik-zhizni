# Стандарт логотипов и иконок проекта

Этот документ задает единые правила для иконок разделов, чтобы интерфейс оставался понятным, аккуратным и удобным на мобильных и десктопных экранах.

## 1) Базовые правила

- Использовать иконки только в стиле `Icons.*_rounded`.
- Для одинаковых сущностей использовать одну и ту же иконку во всем приложении.
- Иконка должна отражать смысл раздела, а не только выглядеть красиво.
- При сомнении выбирать более нейтральный и читаемый символ.

## 2) Размеры и визуальная иерархия

- Нижняя навигация (`bottom nav`): `22` px.
- Боковая навигация (`desktop sidebar`): `24` px.
- Заголовки внутренних секций: `20` px.
- Иконки в карточках: в соответствии с `Responsive.cardIconSize(context)`.

## 3) Цвета и состояния

- Активный пункт: `AppColors.primary`.
- Неактивный пункт: `AppColors.textTertiary`.
- Иконки секций: `AppColors.primary` на мягкой подложке (`primary` с низкой альфой).
- Не использовать случайные локальные цвета для навигационных иконок без дизайн-обоснования.

## 4) Соответствие разделов и иконок

### Главная навигация

- `Молитва` -> `Icons.volunteer_activism_rounded`
- `Профиль` -> `Icons.person_rounded`
- `Админ` -> `Icons.admin_panel_settings_rounded`

### Внутри раздела "Молитва"

- `Молитва за члена церкви` -> `Icons.people_rounded`
- `Глобальные темы` -> `Icons.public_rounded`
- `Служения` -> `Icons.groups_rounded`
- `Отпавшие` -> `Icons.flag_rounded` (допустимо: `Icons.person_off_rounded`)

### Вкладки админ-панели

- `Пользователи` -> `Icons.people_alt_rounded`
- `Календарь` -> `Icons.calendar_month_rounded`
- `Шаблоны` -> `Icons.inventory_2_rounded`
- `Проект` -> `Icons.tune_rounded`

## 5) Проверка удобства (чек-лист)

Перед финальным сохранением иконки проверить:

- Читаемость на светлой и темной теме.
- Читаемость на маленьких экранах (особенно `bottom nav`).
- Отсутствие смыслового конфликта с соседними разделами.
- Единый стиль (`rounded`) и единая визуальная плотность.

## 6) Приоритет на текущий этап

На текущем этапе ключевой раздел — `Молитва`. Любые новые иконки в первую очередь не должны ухудшать его узнаваемость и контраст в навигации.
