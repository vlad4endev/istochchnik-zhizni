# Источник жизни — телефон

Отдельное приложение на Flutter для Android и iOS. Оно ходит в тот же API, что и сайт (`https://app.church-tambov.ru` по умолчанию).

## Запуск

```bash
cd phone
flutter pub get
flutter run
```

Адрес сервера можно сменить в «Ещё → Настройки». Для эмулятора Android локальный API обычно `http://10.0.2.2:40978`.

`flutter run -d chrome` открывает ту же вёрстку в браузере. Браузер блокирует запросы на другой домен, поэтому вход с продакшен-сервера проверяйте на телефоне или эмуляторе.

## Что уже есть

Вход и заявка, профиль с фото и нуждой, лента с публикацией и комментариями, сторис с видео, молитва, чаты с фото, файлами, голосом, опросами и новым диалогом, звонок, Библия, песенник с аккордами, проповеди с плеером и конспектами, мероприятия, служение, расписание, студия, трансляция и заявки администратора. Уже открытые разделы остаются на телефоне, если сеть пропала.

Разделы скрываются по тем же правилам ролей, что и на сайте (`/api/settings/sections`).

## Что ещё впереди

Пока приложение открыто, входящий звонок приходит по тому же каналу, что и на сайте. Пуш при закрытом приложении, релизный ключ Android и ключи Apple для App Store ещё зависят от файлов Firebase и аккаунта разработчика, которых в репозитории нет.
